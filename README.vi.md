## Cuối cùng, hãy nói chuyện như những người bạn thực sự.

Bạn đã ở trong tình huống đó.
Muốn an ủi một người bạn,
nhưng chỉ có thể nói: "Bạn có ổn không?"

Bạn biết rằng "trình dịch" không thể truyền đạt điều trong trái tim bạn.
Vì vậy tôi đã tạo ra một cái có thể.

- **Dịch thuật với LLM** — tiếng lóng, ngôn ngữ nói, trang trọng và thân mật — tất cả được truyền đạt tự nhiên.
- **Bộ nhớ ngữ cảnh** — cuộc trò chuyện diễn ra tự nhiên với nhận thức về ngữ cảnh trước đó.
- **Dịch giọng hai chiều** — cũng dịch giọng của người khác, với hỗ trợ phụ đề VR.
- **Bắt đầu qua Discord** — bắt đầu ngay mà không cần thiết lập phức tạp.

## Câu hỏi thường gặp

- **Chất lượng dịch thuật tốt đến đâu?**
→ Với Gemma 4, kết quả tốt hơn DeepL 6 lần.

- **Mất bao lâu?**
→ Với Gemma 4 và STT đám mây, độ trễ khoảng một giây rưỡi.

- **Có tốn tiền không?**
→ Có, nhưng không phải ngay lập tức. Người dùng mới nhận được tín dụng miễn phí. Sau đó giá rất rẻ — hàng nghìn câu với 1$.

- **Cần API key không?**
→ Có, nhưng không phải ngay lập tức. Chỉ cần cài đặt và xác thực qua Discord.

- **Dịch giọng người khác hoạt động thế nào?**
→ Hoạt động tốt nhất trong cuộc trò chuyện một-một trong môi trường yên tĩnh. Trong VRChat dùng Earmuff.

- **Nhận dạng giọng nói kém/chậm.**
→ Dùng STT đám mây. Trên Intel, chỉ dùng lõi hiệu suất.

- **Dữ liệu được xử lý thế nào?**
→ Giọng nói và nội dung trò chuyện được lưu trữ cục bộ và không gửi đến máy chủ.

## Sử dụng

1. Tải từ [trang tải xuống](https://github.com/kapitalismho/PuriPuly-heart/releases/latest).
2. Cài đặt PuriPuly.
3. Nhấn **STT**.
4. Nhấn **TRANS** và xác thực qua Discord.
5. Nhấn **Subtitles** cho phụ đề VR.
6. Nhấn **Peer** để dịch giọng người khác.
7. Bật OSC trong VRChat: Menu ← Cài đặt ← OSC ← Bật.

Nếu ghi âm không hoạt động, mở **Cài đặt > Chung** và làm theo các bước sau.

2. Chọn micrô đúng.
3. Khởi động lại ứng dụng.

### Ghi chú cho người dùng tại Trung Quốc

Nếu Soniox/Gemini/Deepgram bị chặn trong khu vực của bạn, hãy sử dụng组合 sau:

- STT: **Qwen ASR**
- LLM: **DeepSeek V4 Flash**

   > Bạn có thể xác thực qua QQ thay vì Discord.

### Sử dụng khóa API của riêng bạn

Làm theo hướng dẫn cho dịch vụ bạn muốn sử dụng.

Để dịch, chúng tôi khuyến nghị mô hình Gemma 4 qua OpenRouter.

Cũng hãy cấu hình ASR — PuriPuly mang lại trải nghiệm tốt nhất với STT đám mây.
Ngay cả với cùng Qwen ASR, sự khác biệt giữa nhận dạng cục bộ và đám mây rất rõ ràng.

Chúng tôi khuyến nghị bắt đầu với Deepgram.
Chỉ cần đăng ký là được $200 tín dụng miễn phí.

## Phát triển

### Tóm tắt môi trường

| Khu vực | Môi trường khuyến nghị |
|---|---|
| Ứng dụng Python | Windows |
| Lớp phủ VR | Windows |
| Dịch vụ broker | Linux / WSL |

### Ứng dụng Python

```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
```

```bash
# pip
pip install -e '.[dev]'

# or uv
uv sync --dev
```

```bash
pre-commit install
```

### Chạy giao diện đồ họa

```bash
# After activating venv
python -m puripuly_heart.main run-gui

# or run via uv
uv run python -m puripuly_heart.main run-gui
```

```bash
# Hiển thị giao diện ẩn để kiểm tra
python -m puripuly_heart.main run-gui --debug-ui-preview
```

### Kiểm thử và linting

```bash
black src tests          # Định dạng
ruff check src tests     # Linting
python -m pytest         # Kiểm thử (khuyến nghị trong venv)
```

### Lớp phủ VR

Lớp phủ phụ đề VR được xây dựng từ dự án Rust trong `native/overlay/`.

```powershell
cargo test --manifest-path native/overlay/Cargo.toml -q

cargo build `
  --manifest-path native/overlay/Cargo.toml `
  --locked `
  --release `
  --bin PuriPulyHeartOverlay `
  --target-dir target

New-Item -ItemType Directory -Force -Path build/overlay | Out-Null
Copy-Item target/release/PuriPulyHeartOverlay.exe build/overlay/PuriPulyHeartOverlay.exe -Force
Copy-Item third_party/openvr/win64/openvr_api.dll build/overlay/openvr_api.dll -Force

.\build\overlay\PuriPulyHeartOverlay.exe --check-startup-contract
```

### Dịch vụ broker

Xem `broker/README.md`.

```bash
pnpm install --frozen-lockfile
pnpm run typecheck
pnpm exec vitest run
pnpm --filter @puripuly-heart/broker run verify:config
pnpm --filter @puripuly-heart/broker run dev
```
