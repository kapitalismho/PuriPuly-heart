## W końcu, mów jak prawdziwi przyjaciele.

Byłeś w tej sytuacji.
Chciałeś pocieszyć przyjaciela,
ale udało ci się tylko: "Wszystko dobrze?"

Już wiesz, że "tłumacz" nie może przekazać tego, co masz w sercu.
Dlatego stworzyłem taki, który może.

- **Tłumaczenie napędzane LLM** — slang, potoczne wyrażenia, mowa formalna i nieformalna — wszystko przekazane naturalnie.
- **Pamięć kontekstu** — rozmowa płynie naturalnie ze świadomością wcześniejszego kontekstu.
- **Dwukierunkowe tłumaczenie głosu** — tłumaczy też głos drugiej osoby, z obsługą napisów VR.
- **Start przez Discord** — zacznij od razu bez skomplikowanej konfiguracji.

## Najczęściej zadawane pytania

- **Jak dobra jest jakość tłumaczenia?**
→ Z Gemma 4 wynik jest 6x lepszy niż DeepL.

- **Jak długo to trwa?**
→ Z Gemma 4 i chmurowym STT opóźnienie wynosi około półtorej sekundy.

- **Czy to kosztuje?**
→ Tak, ale nie od razu. Nowi użytkownicy otrzymują darmowy kredyt. Potem ceny są bardzo niskie — tysiące zdań za 1$.

- **Czy potrzebuję klucza API?**
→ Tak, ale nie od razu. Po prostu zainstaluj i uwierzytelnij przez Discord.

- **Jak działa tłumaczenie głosu drugiej osoby?**
→ Najlepiej działa w rozmowach jeden na jeden w cichym otoczeniu. W VRChat użyj Earmuff.

- **Rozpoznawanie mowy jest słabe/wolne.**
→ Użyj chmurowego STT. Na Intelu używaj tylko wydajnych rdzeni.

- **Jak obsługiwane są dane?**
→ Głos i treść rozmowy są przechowywane lokalnie i nie wysyłane na serwery.

## Użycie

1. Pobierz ze [strony pobierania](https://github.com/kapitalismho/PuriPuly-heart/releases/latest).
2. Zainstaluj PuriPuly.
3. Naciśnij **STT**.
4. Naciśnij **TRANS** i uwierzytelnij przez Discord.
5. Naciśnij **Subtitles** dla napisów VR.
6. Naciśnij **Peer** dla tłumaczenia głosu drugiej osoby.
7. Włącz OSC w VRChat: Menu ← Ustawienia ← OSC ← Włącz.

### Jeśli przechwytywanie dźwięku nie działa
Jeśli przechwytywanie dźwięku nie działa, otwórz **Ustawienia > Ogólne** i wykonaj te kroki.

1. Zmień **Audio Host API** na **Auto** lub **MME**.
2. Wybierz właściwy mikrofon.
3. Uruchom aplikację ponownie.

---

### Uwaga dla użytkowników w Chinach

Jeśli Soniox/Gemini/Deepgram są zablokowane w Twoim regionie, użyj następującej kombinacji:

- STT: **Qwen ASR**
- LLM: **DeepSeek V4 Flash**

   > Możesz uwierzytelnić się przez QQ zamiast Discord.

### Korzystanie z własnych kluczy API

Postępuj zgodnie z przewodnikiem dla wybranej usługi.

Do tłumaczenia zalecamy model Gemma 4 przez OpenRouter.

Skonfiguruj także ASR — PuriPuly oferuje najlepsze doświadczenie z chmurowym STT.
Nawet z tym samym Qwen ASR różnica między rozpoznawaniem lokalnym a chmurowym jest zauważalna.

Zalecamy rozpoczęcie od Deepgram.
Sama rejestracja daje $200 darmowego kredytu.

## Rozwój

### Podsumowanie środowiska

| Obszar | Zalecane środowisko |
|---|---|
| Aplikacja Python | Windows |
| Nakładka VR | Windows |
| Usługa brokera | Linux / WSL |

### Aplikacja Python

```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
```

```bash
# pip
pip install -e '.[dev]'

# or uv
uv sync --dev
```

```bash
pre-commit install
```

### Uruchamianie GUI

```bash
# After activating venv
python -m puripuly_heart.main run-gui

# or run via uv
uv run python -m puripuly_heart.main run-gui
```

```bash
# Wyświetla ukryty interfejs do inspekcji
python -m puripuly_heart.main run-gui --debug-ui-preview
```

### Testy i linting

```bash
black src tests          # Formatowanie
ruff check src tests     # Linting
python -m pytest         # Testy (zalecane w venv)
```

### Nakładka VR

Nakładka napisów VR jest budowana z projektu Rust w `native/overlay/`.

```powershell
cargo test --manifest-path native/overlay/Cargo.toml -q

cargo build `
  --manifest-path native/overlay/Cargo.toml `
  --locked `
  --release `
  --bin PuriPulyHeartOverlay `
  --target-dir target

New-Item -ItemType Directory -Force -Path build/overlay | Out-Null
Copy-Item target/release/PuriPulyHeartOverlay.exe build/overlay/PuriPulyHeartOverlay.exe -Force
Copy-Item third_party/openvr/win64/openvr_api.dll build/overlay/openvr_api.dll -Force

.\build\overlay\PuriPulyHeartOverlay.exe --check-startup-contract
```

### Usługa brokera

Zobacz `broker/README.md`.

```bash
pnpm install --frozen-lockfile
pnpm run typecheck
pnpm exec vitest run
pnpm --filter @puripuly-heart/broker run verify:config
pnpm --filter @puripuly-heart/broker run dev
```
