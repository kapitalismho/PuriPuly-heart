## În sfârșit, vorbește ca prieteni adevărați.

Ai fost în acea situație.
Voiai să consoli un prieten,
dar ai reușit doar: "Ești bine?"

Știi deja că un "traducător" nu poate transmite ce ai în inimă.
De aceea am creat unul care poate.

- **Traducere cu LLM** — argou, expresii colocviale, discurs formal și informal — totul transmis natural.
- **Memorie de context** — conversația curge natural cu conștientizarea contextului anterior.
- **Traducere vocală bidirecțională** — traduce și vocea celeilalte persoane, cu suport pentru subtitrări VR.
- **Pornire via Discord** — începe imediat fără configurare complexă.

## Întrebări frecvente

- **Cât de bună este calitatea traducerii?**
→ Cu Gemma 4, rezultatul este de 6x mai bun decât DeepL.

- **Cât durează?**
→ Cu Gemma 4 și STT cloud, latența este de aproximativ o secundă și jumătate.

- **Costă?**
→ Da, dar nu imediat. Utilizatorii noi primesc credit gratuit. După aceea, prețurile sunt foarte mici — mii de propoziții pentru 1$.

- **Am nevoie de o cheie API?**
→ Da, dar nu imediat. Doar instalează și autentifică-te prin Discord.

- **Cum funcționează traducerea vocii celeilalte persoane?**
→ Funcționează cel mai bine în conversații unu-la-unu în medii liniștite. În VRChat folosește Earmuff.

- **Recunoașterea vocală este slabă/lentă.**
→ Folosește STT cloud. Pe Intel, folosește doar nucleele de performanță.

- **Cum sunt gestionate datele?**
→ Vocea și conținutul conversației sunt stocate local și nu sunt trimise la servere.

## Utilizare

1. Descarcă de pe [pagina de descărcare](https://github.com/kapitalismho/PuriPuly-heart/releases/latest).
2. Instalează PuriPuly.
3. Apasă **STT**.
4. Apasă **TRANS** și autentifică-te prin Discord.
5. Apasă **Subtitles** pentru subtitrări VR.
6. Apasă **Peer** pentru traducerea vocii celeilalte persoane.
7. Activează OSC în VRChat: Meniu ← Setări ← OSC ← Activare.

---

---

### Dacă captura audio nu funcționează
Dacă captura audio nu funcționează, deschideți **Setări > General** și urmați acești pași.

1. Schimbați **Audio Host API** la **Auto** sau **MME**.
2. Selectați microfonul corect.
3. Reporniți aplicația.

---

### Notă pentru utilizatorii din China

Dacă Soniox/Gemini/Deepgram sunt blocate în regiunea dvs., utilizați următoarea combinație:

- STT: **Qwen ASR**
- LLM: **DeepSeek V4 Flash**

   > Vă puteți autentifica prin QQ în loc de Discord.

### Folosirea propriilor chei API

Urmați ghidul pentru serviciul dorit.

Pentru traducere, recomandăm modelul Gemma 4 prin OpenRouter.

Configurați și ASR — PuriPuly oferă cea mai bună experiență cu STT cloud.
Chiar și cu același Qwen ASR, diferența dintre recunoașterea locală și cloud este vizibilă.

Recomandăm să începeți cu Deepgram.
Doar înregistrarea vă oferă $200 credit gratuit.

## Dezvoltare

### Rezumat mediu

| Zonă | Mediu recomandat |
|---|---|
| Aplicație Python | Windows |
| Suprapunere VR | Windows |
| Serviciu broker | Linux / WSL |

### Aplicație Python

```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
```

```bash
# pip
pip install -e '.[dev]'

# or uv
uv sync --dev
```

```bash
pre-commit install
```

### Rularea interfeței grafice

```bash
# After activating venv
python -m puripuly_heart.main run-gui

# or run via uv
uv run python -m puripuly_heart.main run-gui
```

```bash
# Afișează interfața ascunsă pentru inspecție
python -m puripuly_heart.main run-gui --debug-ui-preview
```

### Testare și linting

```bash
black src tests          # Formatare
ruff check src tests     # Linting
python -m pytest         # Teste (recomandat în venv)
```

### Suprapunere VR

Suprapunerea subtitrărilor VR este construită din proiectul Rust din `native/overlay/`.

```powershell
cargo test --manifest-path native/overlay/Cargo.toml -q

cargo build `
  --manifest-path native/overlay/Cargo.toml `
  --locked `
  --release `
  --bin PuriPulyHeartOverlay `
  --target-dir target

New-Item -ItemType Directory -Force -Path build/overlay | Out-Null
Copy-Item target/release/PuriPulyHeartOverlay.exe build/overlay/PuriPulyHeartOverlay.exe -Force
Copy-Item third_party/openvr/win64/openvr_api.dll build/overlay/openvr_api.dll -Force

.\build\overlay\PuriPulyHeartOverlay.exe --check-startup-contract
```

### Serviciu broker

Vedeți `broker/README.md`.

```bash
pnpm install --frozen-lockfile
pnpm run typecheck
pnpm exec vitest run
pnpm --filter @puripuly-heart/broker run verify:config
pnpm --filter @puripuly-heart/broker run dev
```
