## أخيراً، تحدث كأصدقاء حقيقيين.

كنت في هذا الموقف.
تريد مواساة صديق،
لكن كل ما تستطيع قوله: "هل أنت بخير؟"

أنت تعرف أن "المترجم" لا يستطيع نقل ما في قلبك.
لذلك بنيت واحداً يستطيع.

- **ترجمة مدعومة بالـ LLM** — اللغة العامية والرسمية، كلها تُنقل بشكل طبيعي.
- **ذاكرة السياق** — المحادثة تتدفق مع الوعي بالسياق السابق.
- **ترجمة صوتية ثنائية الاتجاه** — تترجم صوت الشخص الآخر مع دعم ترجمات VR.
- **البدء عبر Discord** — ابدأ فوراً بدون إعداد معقد.

## الأسئلة الشائعة

- **ما مدى جودة الترجمة؟**
→ مع Gemma 4، النتيجة أفضل بـ 6 مرات من DeepL. انظر قسم "مقارنة الترجمة".

- **كم يستغرق الحصول على الترجمة؟**
→ مع Gemma 4 و STT سحابي، التأخير حوالي ثانية ونصف.

- **هل هو مجاني؟**
→ نعم، لكن ليس فوراً. المستخدمون الجدد يحصلون على رصيد مجاني. بعد ذلك، آلاف العبارات مقابل $1.

- **هل أحتاج مفتاح API؟**
→ نعم، لكن ليس فوراً. فقط ثبّت وصادّق عبر Discord.

- **كيف تعمل ترجمة صوت الشخص الآخر؟**
→ الأفضل في المحادثات الفردية الهادئة. في VRChat استخدم Earmuff.

- **التعرف على الصوت ضعيف؟**
→ استخدم STT سحابي بدلاً من المحلي. على Intel، استخدم النوى عالية الأداء فقط.

- **كيف يتم التعامل مع البيانات؟**
→ الصوت والمحادثة يُخزنان محلياً ولا تُرسل لخوادم PuriPuly.

## الاستخدام

1. حمّل أحدث إصدار من [صفحة التحميل](https://github.com/kapitalismho/PuriPuly-heart/releases/latest).
2. ثبّت PuriPuly.
3. اضغط **STT**.
4. اضغط **TRANS** وصادّق عبر Discord.
5. اضغط **Subtitles** لتشغيل ترجمات VR.
6. (اختياري) اضغط **Peer** لترجمة صوت الشخص الآخر.
7. فعّل OSC في VRChat: قائمة الإجراءات ← الإعدادات ← OSC ← تفعيل.

### إذا لم يعمل التقاط الصوت
إذا لم يعمل التقاط الصوت، افتح **الإعدادات > عام** واتبع هذه الخطوات.

1. غيّر **Audio Host API** إلى **Auto** أو **MME**.
2. اختر الميكروفون الصحيح.
3. أعد تشغيل التطبيق.

## التطوير

### ملخص البيئة

| المنطقة | البيئة الموصى بها |
|---|---|
| تطبيق Python | Windows |
| تراكب VR | Windows |
| خدمة Broker | Linux / WSL |

### تطبيق Python

```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
```

```bash
# pip
pip install -e '.[dev]'

# or uv
uv sync --dev
```

```bash
pre-commit install
```

### تشغيل واجهة المستخدم

```bash
# After activating venv
python -m puripuly_heart.main run-gui

# or run via uv
uv run python -m puripuly_heart.main run-gui
```

```bash
# يعرض واجهة المستخدم المخفية للفحص
python -m puripuly_heart.main run-gui --debug-ui-preview
```

### الاختبار و Linting

```bash
black src tests          # التنسيق
ruff check src tests     # Linting
python -m pytest         # الاختبار (موصى به في venv)
```

### تراكب VR

يتم بناء تراكب ترجمات VR من مشروع Rust في `native/overlay/`.

```powershell
cargo test --manifest-path native/overlay/Cargo.toml -q

cargo build `
  --manifest-path native/overlay/Cargo.toml `
  --locked `
  --release `
  --bin PuriPulyHeartOverlay `
  --target-dir target

New-Item -ItemType Directory -Force -Path build/overlay | Out-Null
Copy-Item target/release/PuriPulyHeartOverlay.exe build/overlay/PuriPulyHeartOverlay.exe -Force
Copy-Item third_party/openvr/win64/openvr_api.dll build/overlay/openvr_api.dll -Force

.\build\overlay\PuriPulyHeartOverlay.exe --check-startup-contract
```

### خدمة Broker

انظر `broker/README.md`.

```bash
pnpm install --frozen-lockfile
pnpm run typecheck
pnpm exec vitest run
pnpm --filter @puripuly-heart/broker run verify:config
pnpm --filter @puripuly-heart/broker run dev
```
