## Inputs, trace and interventions

WAVs are the existing benchmark `audio/{case}.wav`, obtainable from the official AMI recordings and pinned mirror URLs in `../../../manifest.json`; WAV and PCM SHA-256 are checked using that manifest, not personal paths alone. See benchmark `ATTRIBUTION.md` for CC BY 4.0 attribution and source license. Reference timing, labels, identities and speaker counts never enter segmentation or inference. The annotation-selected shortlist is exposed and not an independent holdout.

`factorial/traces/{case}.json` is generated by real current `SileroVadOnnx`, `create_peer_vad_gating`, `PeerAudioSegmentLedger`, `ListenDeliveryController` and `SmartTurnInferenceOwner` with source-real-time audio observations. It freezes sample-exact source pieces, event availability, local seal/cut positions and S200 padding locations. C/D use the current application's `float32_to_pcm16le_bytes(pcm16le_bytes_to_float32(original))` encoder on those exact pieces. A/B retain the complete original PCM. Thus A↔C/B↔D include current PCM quantization as well as skipped silence, replay and S200; these are combined-policy contrasts, not single-factor silence or padding estimates.

A/C finalize only at genuine source completion after their last PCM. B/D finalize at mapped frozen app cuts **and explicitly once more at genuine terminal completion**. If the final app cut equals EOF, this explicit terminal control adds a second control at that position; it is recorded, not hidden as adapter parity. S200 bytes/positions stay in C when intermediate controls disappear. All native milliseconds remain literal: no guessed correction.

Every arm has one WebSocket and a concurrent independent receiver. No arm waits for intermediate `<fin>` before later PCM. Each write waits for source availability and the completion of the preceding chunk's real-time duration; no catch-up burst or future audio. Sender lateness, transport send stalls, pending completion counts, actual PCM digests/sample positions, control writes, receive times, observed processed counters, final tokens and terminal receipt are logged. `<fin>` association is explicitly FIFO diagnostic bookkeeping, not a documented native per-turn identifier guarantee. Protocol failures stop the plan without retry. Reservations persist before connect in the quota ledger, so uncertain interrupted calls cannot silently regain quota.
