## Beidzot, runā kā īsti draugi.

Tu esi bijis šādā situācijā.
Gribēji mierināt draugu,
bet izdevās tikai: "Viss kārtībā?"

Tu jau zini, ka "tulkotājs" nevar nodot to, kas ir tavā sirdī.
Tāpēc es izveidoju tādu, kas var.

- **LLM darbināts tulkojums** — žargons, sarunvaloda, formāla un neformāla runa — viss nodots dabiski.
- **Konteksta atmiņa** — saruna plūst dabiski ar iepriekšējā konteksta apziņu.
- **Divvirzienu balss tulkojums** — tulko arī otras personas balsi, ar VR subtitru atbalstu.
- **Sākšana caur Discord** — sāc uzreiz bez sarežģītas iestatīšanas.

## Bieži uzdotie jautājumi

- **Cik laba ir tulkojuma kvalitāte?**
→ Ar Gemma 4 rezultāts ir 6x labāks nekā DeepL.

- **Cik ilgi tas aizņem?**
→ Ar Gemma 4 un mākoņa STT, aizkave ir apmēram pusotra sekunde.

- **Vai tas maksā?**
→ Jā, bet ne uzreiz. Jauni lietotāji saņem bezmaksas kredītu. Pēc tam cenas ir ļoti zemas — tūkstošiem teikumu par 1$.

- **Vai man vajag API atslēgu?**
→ Jā, bet ne uzreiz. Vienkārši instalē un autentificē caur Discord.

- **Kā darbojas otras balss tulkošana?**
→ Vislabāk darbojas sarunās viens pret vienu klusā vidē. VRChat izmanto Earmuff.

- **Balss atpazīšana ir slikta/lēna.**
→ Izmanto mākoņa STT. Uz Intel izmanto tikai veiktspējas kodolus.

- **Kā tiek apstrādāti dati?**
→ Balss un sarunas saturs tiek glabāts lokāli un netiek sūtīts uz serveriem.

## Lietošana

1. Lejupielādē no [lejupielādes lapas](https://github.com/kapitalismho/PuriPuly-heart/releases/latest).
2. Instalē PuriPuly.
3. Nospied **STT**.
4. Nospied **TRANS** un autentificē caur Discord.
5. Nospied **Subtitles** VR subtitriem.
6. Nospied **Peer** otras balss tulkošanai.
7. Ieslēdz OSC VRChat: Izvēlne ← Iestatījumi ← OSC ← Ieslēgt.

## Izstrāde

### Vides pārskats

| Joma | Ieteicamā vide |
|---|---|
| Python lietotne | Windows |
| VR pārklājums | Windows |
| Broker pakalpojums | Linux / WSL |

### Python lietotne

```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
```

```bash
# pip
pip install -e '.[dev]'

# or uv
uv sync --dev
```

```bash
pre-commit install
```

### GUI palaišana

```bash
# After activating venv
python -m puripuly_heart.main run-gui

# or run via uv
uv run python -m puripuly_heart.main run-gui
```

```bash
# Rāda paslēpto UI pārbaudei
python -m puripuly_heart.main run-gui --debug-ui-preview
```

### Testēšana un linting

```bash
black src tests          # Formatēšana
ruff check src tests     # Linting
python -m pytest         # Testi (ieteicams venv)
```

### VR pārklājums

VR subtitru pārklājums tiek veidots no Rust projekta `native/overlay/`.

```powershell
cargo test --manifest-path native/overlay/Cargo.toml -q

cargo build `
  --manifest-path native/overlay/Cargo.toml `
  --locked `
  --release `
  --bin PuriPulyHeartOverlay `
  --target-dir target

New-Item -ItemType Directory -Force -Path build/overlay | Out-Null
Copy-Item target/release/PuriPulyHeartOverlay.exe build/overlay/PuriPulyHeartOverlay.exe -Force
Copy-Item third_party/openvr/win64/openvr_api.dll build/overlay/openvr_api.dll -Force

.\build\overlay\PuriPulyHeartOverlay.exe --check-startup-contract
```

### Broker pakalpojums

Skatiet `broker/README.md`.

```bash
pnpm install --frozen-lockfile
pnpm run typecheck
pnpm exec vitest run
pnpm --filter @puripuly-heart/broker run verify:config
pnpm --filter @puripuly-heart/broker run dev
```
