## Eindelijk, praat als echte vrienden.

Je bent in die situatie geweest.
Je wilde een vriend troosten,
maar het lukte alleen: "Gaat het wel?"

Je weet al dat een "vertaler" niet kan overbrengen wat er in je hart zit.
Daarom heb ik er een gemaakt die dat wel kan.

- **LLM-gestuurde lokalisering** — slang, spreektaal, formeel en informeel spraak — alles natuurlijk weergegeven.
- **Contextgeheugen** — het gesprek stroomt natuurlijk met bewustzijn van eerdere context.
- **Tweerichting spraakvertaling** — vertaalt ook de stem van de andere persoon, met VR-ondertitelondersteuning.
- **Start via Discord** — begin direct zonder complexe setup.

## Veelgestelde vragen

- **Hoe goed is de vertaalkwaliteit?**
→ Met Gemma 4 is het resultaat 6x beter dan DeepL.

- **Hoe lang duurt het?**
→ Met Gemma 4 en cloud STT is de vertraging ongeveer anderhalve seconde.

- **Kost het geld?**
→ Ja, maar niet direct. Nieuwe gebruikers krijgen gratis tegoed. Daarna zijn de prijzen erg laag — duizenden zinnen voor 1$.

- **Heb ik een API-sleutel nodig?**
→ Ja, maar niet direct. Installeer en authentificeer via Discord.

- **Hoe werkt de vertaling van de stem van de ander?**
→ Werkt het beste in een-op-een gesprekken in een rustige omgeving. In VRChat gebruik Earmuff.

- **Spraakherkenning is slecht/traag.**
→ Gebruik cloud STT. Op Intel, gebruik alleen prestatiekernen.

- **Hoe worden gegevens beheerd?**
→ Stem en gespreksinhoud worden lokaal opgeslagen en niet naar servers gestuurd.

## Gebruik

1. Download van de [downloadpagina](https://github.com/kapitalismho/PuriPuly-heart/releases/latest).
2. Installeer PuriPuly.
3. Druk op **STT**.
4. Druk op **TRANS** en authentificeer via Discord.
5. Druk op **Subtitles** voor VR-ondertitels.
6. Druk op **Peer** voor vertaling van de stem van de ander.
7. Schakel OSC in VRChat: Menu ← Instellingen ← OSC ← Inschakelen.

---

---

### Als audio-opname niet werkt
Als audio-opname niet werkt, open **Instellingen > Algemeen** en volg deze stappen.

1. Wijzig **Audio Host API** naar **Auto** of **MME**.
2. Selecteer de juiste microfoon.
3. Start de app opnieuw.

### Gebruik je eigen API-sleutels

Volg de gids voor de gewenste service.

Voor vertaling raden we het Gemma 4 model aan via OpenRouter.

Stel ook ASR in — PuriPuly biedt de beste ervaring met cloud STT.
Zelfs met dezelfde Qwen ASR is het verschil tussen lokale en cloudherkenning merkbaar.

We raden aan te beginnen met Deepgram.
Alleen al registreren geeft $200 gratis tegoed.

## Ontwikkeling

### Omgevingsoverzicht

| Gebied | Aanbevolen omgeving |
|---|---|
| Python-app | Windows |
| VR-overlay | Windows |
| Broker-dienst | Linux / WSL |

### Python-app

```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
```

```bash
# pip
pip install -e '.[dev]'

# or uv
uv sync --dev
```

```bash
pre-commit install
```

### GUI starten

```bash
# After activating venv
python -m puripuly_heart.main run-gui

# or run via uv
uv run python -m puripuly_heart.main run-gui
```

```bash
# Toont de verborgen interface voor inspectie
python -m puripuly_heart.main run-gui --debug-ui-preview
```

### Testen en linting

```bash
black src tests          # Formattering
ruff check src tests     # Linting
python -m pytest         # Tests (aanbevolen in venv)
```

### VR-overlay

De VR-ondertitel-overlay wordt gebouwd vanuit het Rust-project in `native/overlay/`.

```powershell
cargo test --manifest-path native/overlay/Cargo.toml -q

cargo build `
  --manifest-path native/overlay/Cargo.toml `
  --locked `
  --release `
  --bin PuriPulyHeartOverlay `
  --target-dir target

New-Item -ItemType Directory -Force -Path build/overlay | Out-Null
Copy-Item target/release/PuriPulyHeartOverlay.exe build/overlay/PuriPulyHeartOverlay.exe -Force
Copy-Item third_party/openvr/win64/openvr_api.dll build/overlay/openvr_api.dll -Force

.\build\overlay\PuriPulyHeartOverlay.exe --check-startup-contract
```
