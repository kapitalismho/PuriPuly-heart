## Нарешті, говоріть як справжні друзі.

Ви були в цій ситуації.
Хтіли втішити друга,
але змогли лише: "Ти в порядку?"

Ви вже знаєте, що "перекладач" не може передати те, що у вашому серці.
Тому я створив такий, який може.

- **Переклад на базі LLM** — сленг, розмовні вирази, формальна та неформальна мова — все передається природно.
- **Пам'ять контексту** — розмова тече природно з урахуванням попереднього контексту.
- **Двосторонній голосовий переклад** — також перекладає голос іншої людини, з підтримкою VR субтитрів.
- **Старт через Discord** — починайте одразу без складного налаштування.

## Часті питання

- **Наскільки хороша якість перекладу?**
→ З Gemma 4 результат у 6 разів кращий за DeepL.

- **Скільки часу це займає?**
→ З Gemma 4 та хмарним STT затримка близько півтори секунди.

- **Чи це коштує?**
→ Так, але не одразу. Нові користувачі отримують безкоштовний кредит. Після цього ціни дуже низькі — тисячі фраз за 1$.

- **Чи потрібен API ключ?**
→ Так, але не одразу. Просто встановіть та автентифікуйтесь через Discord.

- **Як працює переклад голосу іншої людини?**
→ Найкраще працює в розмовах один на один в тихому середовищі. У VRChat використовуйте Earmuff.

- **Розпізнавання голосу погане/повільне.**
→ Використовуйте хмарний STT. На Intel використовуйте лише продуктивні ядра.

- **Як обробляються дані?**
→ Голос та вміст розмови зберігаються локально і не надсилаються на сервери.

## Використання

1. Завантажте зі [сторінки завантаження](https://github.com/kapitalismho/PuriPuly-heart/releases/latest).
2. Встановіть PuriPuly.
3. Натисніть **STT**.
4. Натисніть **TRANS** та автентифікуйтесь через Discord.
5. Натисніть **Subtitles** для VR субтитрів.
6. Натисніть **Peer** для перекладу голосу іншої людини.
7. Увімкніть OSC у VRChat: Меню ← Налаштування ← OSC ← Увімкнути.

### Якщо захоплення звуку не працює
Якщо захоплення звуку не працює, відкрийте **Налаштування > Загальні** та виконайте ці кроки.

1. Змініть **Audio Host API** на **Auto** або **MME**.
2. Виберіть правильний мікрофон.
3. Перезапустіть додаток.

---

### Примітка для користувачів у Китаї

Якщо Soniox/Gemini/Deepgram заблоковані у вашому регіоні, використовуйте таку комбінацію:

- STT: **Qwen ASR**
- LLM: **DeepSeek V4 Flash**

   > Ви можете автентифікуватися через QQ замість Discord.

Рекомендуємо почати з Deepgram.

## Розробка

### Огляд середовища

| Область | Рекомендоване середовище |
|---|---|
| Python-додаток | Windows |
| VR-накладка | Windows |
| Сервіс брокера | Linux / WSL |

### Python-додаток

```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
```

```bash
# pip
pip install -e '.[dev]'

# or uv
uv sync --dev
```

```bash
pre-commit install
```

### Запуск GUI

```bash
# After activating venv
python -m puripuly_heart.main run-gui

# or run via uv
uv run python -m puripuly_heart.main run-gui
```

```bash
# Показує прихований інтерфейс для перевірки
python -m puripuly_heart.main run-gui --debug-ui-preview
```

### Тестування та лінтинг

```bash
black src tests          # Форматування
ruff check src tests     # Лінтинг
python -m pytest         # Тести (рекомендовано у venv)
```

### VR-накладка

VR-накладка субтитрів створюється з Rust-проєкту в `native/overlay/`.

```powershell
cargo test --manifest-path native/overlay/Cargo.toml -q

cargo build `
  --manifest-path native/overlay/Cargo.toml `
  --locked `
  --release `
  --bin PuriPulyHeartOverlay `
  --target-dir target

New-Item -ItemType Directory -Force -Path build/overlay | Out-Null
Copy-Item target/release/PuriPulyHeartOverlay.exe build/overlay/PuriPulyHeartOverlay.exe -Force
Copy-Item third_party/openvr/win64/openvr_api.dll build/overlay/openvr_api.dll -Force

.\build\overlay\PuriPulyHeartOverlay.exe --check-startup-contract
```

### Сервіс брокера

Див. `broker/README.md`.

```bash
pnpm install --frozen-lockfile
pnpm run typecheck
pnpm exec vitest run
pnpm --filter @puripuly-heart/broker run verify:config
pnpm --filter @puripuly-heart/broker run dev
```
