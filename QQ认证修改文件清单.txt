QQ 认证修改文件清单
==================

说明：本次改动为「托管（中国）」入口新增 QQ 号 + 凭证认证链路。
用户在客户端输入 QQ 号和 QQ 群机器人下发的 HMAC 凭证后，客户端
POST 到服务器端 Broker（https://puripuly-heart-broker.kapitalismho.workers.dev/
v1/auth/qq/assert），服务器验证后返回 OpenRouter API key。

Discord 认证和 QQ 认证完全独立：
- Discord key 存到 openrouter_managed_api_key
- QQ key 存到 openrouter_managed_qq_api_key
- 选「托管」走 Discord，选「托管（中国）」走 QQ，互不影响

验证方式
--------
1. Python（本仓库根目录）：
   uv sync  # 安装依赖
   python -m puripuly_heart.main  # 启动应用

2. 手动端到端：
   - 启动应用 -> 选择「托管（中国）」 -> 点击翻译或在 Settings Apply。
   - 弹出 QQ 认证弹窗 -> 输入 QQ 号 + 机器人下发的凭证 -> 提交。
   - 客户端 POST 到 salee 的 broker 服务器。
   - 成功后自动进入翻译流程。
   - 即使已有 Discord key，选「托管（中国）」仍会弹 QQ 框。


请求规范
--------
POST https://puripuly-heart-broker.kapitalismho.workers.dev/v1/auth/qq/assert

Headers: Content-Type: application/json

Body:
{
  "qq_identity": "用户的明文QQ号",
  "credential": "机器人下发的64位全小写HMAC凭证",
  "asserted_at": "2026-06-05T12:03:00.000Z"
}
