Shipped/runtime component license summary

This notice file focuses on components that are bundled, shipped, installed, or used by the runtime/broker service. Build-only and test-only dependency inventory is recorded in the AGPL transition ADR and verification log instead of being treated as shipped notice text.

The technical metadata review performed for the AGPL transition found no obvious license blocker to licensing PuriPuly Heart's own code under AGPL-3.0-or-later. This is a repository metadata review, not legal advice.

Notable shipped/runtime license families include MIT, Apache-2.0, BSD-3-Clause, MPL-2.0, LGPL-2.1-or-later, SIL Open Font License 1.1, CC-BY-4.0, and GPL-2.0-or-later WITH Bootloader-exception for PyInstaller-built binaries.
