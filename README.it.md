## Finalmente, parla come veri amici.

Sei stato in quella situazione.
Volevi consolare un amico,
ma sei riuscito solo a dire: "Stai bene?"

Sai già che un "traduttore" non può trasmettere ciò che hai nel cuore.
Per questo ne ho creato uno che può.

- **Traduzione basata su LLM** — gergo, espressioni colloquiali, discorso formale e informale — tutto reso naturalmente.
- **Memoria del contesto** — la conversazione scorre naturalmente con consapevolezza del contesto precedente.
- **Traduzione vocale bidirezionale** — traduce anche la voce dell'altra persona, con supporto sottotitoli VR.
- **Avvio via Discord** — inizia subito senza configurazione complessa.

## Domande frequenti

- **Com'è la qualità della traduzione?**
→ Con Gemma 4, il risultato è 6x migliore di DeepL.

- **Quanto tempo ci vuole?**
→ Con Gemma 4 e STT cloud, la latenza è di circa un secondo e mezzo.

- **Costa?**
→ Sì, ma non subito. I nuovi utenti ottengono credito gratuito. Dopo, i prezzi sono bassissimi — migliaia di frasi per 1$.

- **Ho bisogno di una chiave API?**
→ Sì, ma non subito. Basta installare e autenticarsi via Discord.

- **Come funziona la traduzione della voce dell'altro?**
→ Funziona meglio in conversazioni uno-a-uno in ambienti silenziosi. In VRChat usa Earmuff.

- **Il riconoscimento vocale è scarso/lento.**
→ Usa STT cloud. Su Intel, usa solo i core ad alte prestazioni.

- **Come vengono gestiti i dati?**
→ La voce e il contenuto della conversazione sono archiviati localmente e non inviati a server.

## Utilizzo

1. Scarica dalla [pagina download](https://github.com/kapitalismho/PuriPuly-heart/releases/latest).
2. Installa PuriPuly.
3. Premi **STT**.
4. Premi **TRANS** e autenticati via Discord.
5. Premi **Subtitles** per i sottotitoli VR.
6. Premi **Peer** per la traduzione della voce dell'altro.
7. Abilita OSC in VRChat: Menu ← Impostazioni ← OSC ← Abilita.

---

---

### Se la cattura audio non funziona
Se la cattura audio non funziona, apri **Impostazioni > Generale** e segui questi passaggi.

1. Cambia **Audio Host API** in **Auto** o **MME**.
2. Seleziona il microfono corretto.
3. Riavvia l'app.

### Usare le proprie chiavi API

Segui la guida del servizio che vuoi utilizzare.

Per la traduzione, raccomandiamo il modello Gemma 4 tramite OpenRouter.

Approfitta per configurare ASR — PuriPuly offre la migliore esperienza con STT cloud.
Anche con lo stesso Qwen ASR, la differenza tra riconoscimento locale e cloud è evidente.

Consigliamo di iniziare con Deepgram.
La sola registrazione ti dà $200 di credito gratuito.

## Sviluppo

### Riepilogo ambiente

| Area | Ambiente consigliato |
|---|---|
| App Python | Windows |
| Sovrapposizione VR | Windows |
| Servizio broker | Linux / WSL |

### App Python

```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
```

```bash
# pip
pip install -e '.[dev]'

# or uv
uv sync --dev
```

```bash
pre-commit install
```

### Avvio dell'interfaccia grafica

```bash
# After activating venv
python -m puripuly_heart.main run-gui

# or run via uv
uv run python -m puripuly_heart.main run-gui
```

```bash
# Mostra l'interfaccia nascosta per l'ispezione
python -m puripuly_heart.main run-gui --debug-ui-preview
```

### Test e linting

```bash
black src tests          # Formattazione
ruff check src tests     # Linting
python -m pytest         # Test (consigliato in venv)
```

### Sovrapposizione VR

La sovrapposizione sottotitoli VR è costruita dal progetto Rust in `native/overlay/`.

```powershell
cargo test --manifest-path native/overlay/Cargo.toml -q

cargo build `
  --manifest-path native/overlay/Cargo.toml `
  --locked `
  --release `
  --bin PuriPulyHeartOverlay `
  --target-dir target

New-Item -ItemType Directory -Force -Path build/overlay | Out-Null
Copy-Item target/release/PuriPulyHeartOverlay.exe build/overlay/PuriPulyHeartOverlay.exe -Force
Copy-Item third_party/openvr/win64/openvr_api.dll build/overlay/openvr_api.dll -Force

.\build\overlay\PuriPulyHeartOverlay.exe --check-startup-contract
```

### Servizio broker

Vedi `broker/README.md` per i dettagli.

```bash
pnpm install --frozen-lockfile
pnpm run typecheck
pnpm exec vitest run
pnpm --filter @puripuly-heart/broker run verify:config
pnpm --filter @puripuly-heart/broker run dev
```
