本政策适用于 PuriPuly 应用和项目运营的服务器。外部服务适用其自身政策。

1. 使用统计与您的选择

- 为估算用户数量，应用会发送随机标识符和 UTC 活动日期。服务器保存派生的标识符及这些日期，与账号认证信息分开。统计不包含对话、音频、翻译或 API 密钥。
- 新安装默认开启统计。在安装程序的隐私政策页面选择不同意，会在首次启动前关闭统计，且不影响安装。之后可在设置中更改；升级会保留您的选择。
- 关闭统计会停止发送并删除本地标识符。重新开启会生成新的标识符。服务器记录会保留至清理时；清理会删除活动日期距 UTC 今天超过 35 天的记录，仍可能保留包括今天在内的 36 个日期的记录。

2. 音频、翻译与集成

- 本地模型在设备上处理数据。外部语音识别会发送音频；外部翻译会发送文本和必要上下文。所选服务和自定义服务器会收到为其配置的认证信息，并适用各自的保留和训练政策。
- 新安装选择 Bilibili 在 index-translate.bilibili.com 提供的免密钥 Index-Translate 35B API。启动应用及选择该服务时，即使翻译关闭，也会发送不含对话内容的合成文本请求以检查可用性。普通翻译可能将同一请求发送两次。服务不可用时，保存的选择会改为 Gemma 4 Managed；若已确认 Managed 额度耗尽，则改为 Gemma 4 OpenRouter。所选路径使用其正常的认证和处理流程。不保证免费可用。
- 托管翻译会连同用户引用值发送至 OpenRouter 及其推理提供商，不经过项目认证服务器。选择本地模型或关闭相应功能可避免外部处理。
- VRChat 上下文可能包含参与人数，但不含姓名或原始日志。OSC 向配置的目标发送字幕和控制信息，自动连接时会在局域网中发现和广播服务。默认目标位于本机；可在设置中更改或关闭。

3. 托管账号与安全

Discord、QQ 和托管服务会处理认证数据、账号引用值、安装/设备标识符和硬件哈希，用于访问控制、使用权限、密钥交付和防止滥用。服务器记录包括使用权限、密钥发放、奖励和基于 IP 的安全信息。这些信息与可选统计分开，保留期限也不同。活动与密钥发放汇总会发送至运营用的 Discord 频道。

4. 关闭统计后仍会发生的通信

应用启动时会向 GitHub 检查更新，并从 Hugging Face 或 ModelScope 等服务下载模型。认证和外部功能的通信独立于统计。使用本地模型并关闭统计，也不会使应用完全离线。

更新/下载请求不含统计标识符、对话或音频，但接收方和 Cloudflare 基础设施会处理 IP 地址及一般请求元数据。删除服务器记录不会立即清除备份或旧版本的记录。

5. 本地信息与删除

设置、模型和日志主要保存在 %LOCALAPPDATA%\puripuly-heart。运行日志包含识别文本和翻译，记录长度有限。Basic 和 Detailed 日志都会遮盖符合已知秘密信息模式的内容，但仍可能留下敏感文字。共享日志前请检查并遮盖敏感内容。

凭据保存在 Windows 凭据管理器或加密文件中。删除应用数据文件夹不会清除所有凭据或外部服务记录。

6. Puri 助手与自愿支持报告

助手请求

Puri 在您发送消息时启动，无需单独的同意对话框。消息、必要的对话/工具结果，以及列入允许清单的应用状态和诊断摘要，会经项目的 relay 发送至 OpenAI。不会自动包含语音转写、翻译、音频、原始日志、完整设置或密钥。

请仅在设置的安全输入框中填写密钥，切勿在聊天中输入。已知模式拦截无法识别所有秘密信息。Puri 历史保存在应用内存中，与语音转写分开。重置后可能保留本次应用运行的报告存档；重启应用会清除它。

Broker 验证安装身份并签发短期令牌。Relay 和 OpenAI 收到的是派生的安装标识符（HMAC），而非原始 ID。必需的用量、费用及错误统计，以及随机提示轮次标识符，均与可选统计分开。每日限额按提交的提示轮次计算，而非模型调用次数或费用。普通 relay 存储和日志不保留对话内容、设置值或原始诊断数据。

OpenAI 的 store:false 不等于 Zero Data Retention。根据其数据控制说明（查阅日期：2026-10-30）：
- 除非主动选择参与，否则 API 数据不会用于训练。
- 滥用监控内容可保留最多 30 天；因法律或防止伤害需要，可能保留更久。
- 加密提示缓存张量可保留最多 24 小时。
- 特殊保留控制需供应商批准。
https://developers.openai.com/api/docs/guides/your-data

自愿支持报告

只有点击说明旁的“发送”才会上传报告。仅提出建议不会创建或上传任何内容。报告包含：
- 本次应用运行的完整 Puri 对话，包括重置前的内容、工具调用/结果及通知；不含推理数据。
- 仅当前应用日志，含识别文本和翻译。
- 元数据。

遮盖无法去除所有敏感文字。报告发送至仅开发者可访问的 R2 存储，生命周期为 30 天；通常在到期后约 24 小时内删除。Discord 通知仅含工单编号、应用版本、压缩大小和诊断代码。

报告压缩后上限为 25 MB，每个安装实例每日（UTC）最多 3 份，与模型用量分开计算。发送失败需主动重试。
