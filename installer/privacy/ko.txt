이 방침은 PuriPuly 앱과 프로젝트 운영 서버에 적용됩니다. 외부 서비스에는 해당 서비스의 정책이 적용됩니다.

1. 사용 통계와 선택

- 사용자 수를 추정하기 위해 무작위 식별자와 사용 날짜(UTC)를 보냅니다. 서버는 변환한 식별자와 날짜를 계정 인증 정보와 분리해 저장합니다. 통계에는 대화, 음성, 번역 결과, API 키가 포함되지 않습니다.
- 신규 설치는 통계가 기본으로 켜집니다. 설치의 개인정보처리방침 페이지에서 동의하지 않으면 첫 실행부터 통계를 보내지 않으며, 설치는 계속할 수 있습니다. 이후 설정에서 변경할 수 있고, 업그레이드는 기존 선택을 유지합니다.
- 끄면 전송을 중단하고 기기의 식별자를 삭제합니다. 다시 켜면 새 식별자를 만듭니다. 서버 기록은 정리 시점까지 남으며, UTC 기준 35일을 초과한 활동을 삭제합니다. 오늘을 포함한 36개 날짜의 기록이 남을 수 있습니다.

2. 음성, 번역과 연동

- 로컬 모델은 기기에서 처리합니다. 외부 음성 인식에는 음성을, 외부 번역에는 원문과 필요한 문맥을 보냅니다. 선택한 서비스와 사용자 지정 서버에는 설정한 인증정보도 전달됩니다. 보관과 학습 이용은 해당 서비스의 정책에 따릅니다.
- 신규 설치는 Bilibili의 키 없는 Index-Translate 35B API(index-translate.bilibili.com)를 선택합니다. 선택하거나 선택된 상태로 시작하면 번역이 꺼져 있어도 대화 내용 없는 합성 문장으로 가용성을 확인합니다. 일반 번역은 같은 요청을 두 번 보낼 수 있습니다. 이용 불가 시 Gemma 4 Managed로 선택을 바꾸고 저장하며, 관리형 잔여량 소진이 확인된 경우 Gemma 4 OpenRouter로 전환합니다. 전환된 경로의 인증과 외부 처리 절차가 적용됩니다. 무료 제공은 보장하지 않습니다.
- 관리형 번역은 사용자 참조값과 함께 OpenRouter와 추론 제공자에 전달되며, 프로젝트 인증 서버를 거치지 않습니다. 외부 처리를 피하려면 로컬 모델을 선택하거나 해당 기능을 끄세요.
- VRChat 문맥에는 참가자 수가 포함될 수 있지만, 이름이나 원본 로그는 보내지 않습니다. OSC는 설정한 대상에 자막과 제어 정보를 보내며, 자동 연결 시 로컬 네트워크에서 서비스를 검색하고 광고합니다. 기본 대상은 기기 내부이며, 설정에서 변경하거나 끌 수 있습니다.

3. 관리형 계정과 보안

Discord, QQ와 관리형 서비스는 인증, 이용권한 확인, 키 전달과 부정 이용 방지를 위해 인증정보, 계정 참조값, 설치·장치 식별정보와 하드웨어 해시를 처리합니다. 서버는 이용권한, 키 발급, 보상과 IP 기반 보안 기록을 저장합니다. 이는 선택적 통계와 별개이며 보관 기간도 다릅니다. 활동과 키 발급 집계는 운영용 Discord 채널로 보냅니다.

4. 통계를 꺼도 발생하는 통신

앱은 시작 시 GitHub에서 업데이트를 확인하고, Hugging Face나 ModelScope 등에서 모델을 다운로드합니다. 인증과 외부 기능은 통계와 별도로 통신합니다. 로컬 모델을 쓰고 통계를 꺼도 완전한 오프라인 상태가 되지는 않습니다.

업데이트·다운로드 요청에는 통계 식별자, 대화, 음성을 넣지 않지만, 수신 서비스와 Cloudflare 기반시설은 IP 주소와 일반 요청 정보를 처리합니다. 서버 기록을 삭제해도 백업과 이전 버전의 기록이 즉시 삭제되지는 않습니다.

5. 기기에 남는 정보와 삭제

설정, 모델과 로그는 주로 %LOCALAPPDATA%\puripuly-heart에 저장됩니다. 런타임 로그에는 인식된 텍스트와 번역이 포함되며, 레코드 길이는 제한됩니다. Basic과 Detailed 로그 모두 알려진 비밀정보 패턴을 가리지만 민감한 문구는 남을 수 있습니다. 공유 전에 내용을 확인하고 민감한 부분을 삭제하세요.

인증정보는 Windows 자격 증명 저장소 또는 암호화된 파일에 보관합니다. 앱 데이터 폴더를 지워도 모든 인증정보나 외부 서비스 기록이 삭제되지는 않습니다.

6. Puri 도우미와 자발적 지원 보고서

도우미 요청

Puri는 별도 동의창 없이 메시지를 보내면 시작됩니다. 메시지, 필요한 대화·도구 결과와 허용된 앱 상태·진단 요약이 프로젝트 중계 서버를 거쳐 OpenAI로 전달됩니다. 음성 대화록, 번역문, 음성, 원본 로그, 전체 설정과 키는 자동으로 포함하지 않습니다.

키는 채팅이 아닌 설정의 보안 입력란에만 입력하세요. 알려진 패턴 차단으로 모든 비밀정보를 탐지할 수는 없습니다. Puri 기록은 음성 대화록과 별도로 앱 메모리에 보관합니다. 초기화 후에도 현재 실행의 보고서용 기록은 남을 수 있으며, 재시작하면 지워집니다.

Broker는 설치를 인증하고 단기 토큰을 발급합니다. 중계 서버와 OpenAI에는 원본 설치 ID 대신 파생 식별자(HMAC)를 보냅니다. 필수 사용량·비용·오류 집계와 무작위 프롬프트 턴 식별자는 선택적 통계와 별개입니다. 일일 한도는 모델 호출 수나 비용이 아닌 제출한 프롬프트 턴 수로 계산합니다. 일반 중계 저장소와 로그에는 대화 내용, 설정값, 원본 진단을 보관하지 않습니다.

OpenAI의 store:false는 Zero Data Retention을 뜻하지 않습니다. 2026-10-30 확인한 데이터 정책에 따르면:
- 명시적으로 참여하지 않으면 API 데이터를 학습에 사용하지 않습니다.
- 부정 사용 모니터링 내용은 최대 30일, 법률·위해 방지 사유로는 더 오래 보관될 수 있습니다.
- 암호화된 프롬프트 캐시 텐서는 최대 24시간 보관될 수 있습니다.
- 특별 보관 제어에는 제공자 승인이 필요합니다.
https://developers.openai.com/api/docs/guides/your-data
