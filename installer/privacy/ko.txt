이 방침은 PuriPuly 앱과 프로젝트가 운영하는 서버에 적용됩니다. 선택한 외부 서비스에는 해당 서비스의 정책도 적용됩니다.

1. 사용 통계와 선택

사용자 수를 추정하기 위해 무작위 식별자와 앱 사용 날짜(UTC)를 보냅니다. 통계에는 대화, 음성, 번역 결과, API 키가 포함되지 않습니다. 서버는 식별자를 변환해 활동 날짜와 저장하며, 계정 인증 정보와 연결하지 않습니다.

신규 설치에서는 통계가 기본으로 켜집니다. 설치 중 ‘익명 사용 통계 보내기’를 해제하면 첫 실행부터 통계를 보내지 않습니다. 설치 후 설정에서도 변경할 수 있으며, 업그레이드는 직접 변경하지 않는 한 기존 선택을 유지합니다. 기본 체크 상태를 별도의 동의 표시로 취급하지 않습니다.

끄면 이후 통계 전송을 중단하고 기기의 통계 식별자를 제거합니다. 다시 켜면 새 식별자를 만듭니다. 이미 서버에 저장된 활동은 즉시 삭제되지 않습니다. 정기 정리에서는 UTC 기준 오늘보다 35일을 초과해 오래된 활동을 삭제하므로, 정리 후 오늘을 포함한 36개 날짜의 기록이 남을 수 있습니다.

2. 음성, 번역과 연동

로컬 모델은 기기에서 처리합니다. 외부 음성 인식에는 음성을, 외부 번역에는 원문과 필요한 문맥을 선택한 서비스에 보냅니다. API 키는 서비스 인증에 사용됩니다. 사용자 지정 서버에도 설정한 음성 또는 텍스트와 인증정보가 전달됩니다.

관리형 번역은 OpenRouter와 실제 추론 제공자가 처리하며, 사용자 참조값이 포함됩니다. 프로젝트 인증 서버가 통상적인 번역 본문을 중계하지는 않습니다. 외부 서비스의 보관과 학습 이용은 해당 정책과 설정에 따르며, 모든 요청의 무보관이나 학습 미사용을 보장하지 않습니다. 외부 처리를 원하지 않으면 로컬 모델을 선택하거나 해당 기능을 끌 수 있습니다.

VRChat 연동은 참가자 수를 번역 문맥에 포함할 수 있지만, 참가자 이름과 원본 로그는 보내지 않습니다. OSC는 설정한 대상에 자막과 제어 정보를 보내며, 자동 연결은 로컬 네트워크에서 서비스를 검색하고 광고합니다. 기본 대상은 기기 내부이며, 설정에서 연결 모드를 변경하거나 끌 수 있습니다.

3. 관리형 계정과 보안

관리형 인증에는 Discord 또는 QQ 같은 계정 서비스가 사용됩니다. 관리형 서비스는 인증, 이용권한 확인, 키 전달과 부정 이용 방지를 위해 계정 인증정보, 설치와 장치 식별정보, 하드웨어 정보의 해시 등을 처리합니다. 서버에는 계정 참조값, 이용권한, 키 발급과 보상 기록, IP 기반 보안 기록 등이 저장됩니다. 이는 사용 통계와 별개이며, 모든 기록에 같은 보관 기간이 적용되지는 않습니다. 운영용 Discord 채널에는 활동과 키 발급 등의 집계를 전달합니다.

4. 통계를 꺼도 발생하는 통신

앱 시작 시 GitHub에서 업데이트를 확인하고, 필요한 모델은 Hugging Face 또는 ModelScope 등에서 다운로드합니다. 인증과 사용자가 선택한 외부 기능의 통신도 별도로 발생합니다. 로컬 모델을 사용하거나 통계를 꺼도 이러한 통신이 모두 중단되지는 않습니다.

다운로드와 업데이트 요청에 통계 식별자, 대화, 음성을 넣지는 않지만, 접속 서비스는 IP 주소와 일반적인 요청 정보를 처리합니다. 프로젝트 서버의 Cloudflare 기반시설 처리도 통계 본문의 두 항목과 별개입니다. 서버 기록 삭제가 백업이나 이전 버전의 기록까지 즉시 모두 삭제한다는 뜻은 아닙니다.

5. 기기에 남는 정보와 삭제

설정, 모델과 진단 로그는 주로 %LOCALAPPDATA%\puripuly-heart에 저장됩니다. API 키 등의 비밀정보는 Windows 자격 증명 저장소 또는 암호화된 파일에 보관됩니다. 진단 로그를 공유하기 전에는 내용을 확인하세요. 앱 제거로 앱 데이터 폴더를 정리해도 Windows 자격 증명 저장소나 외부 서비스의 정보까지 모두 삭제되지는 않습니다.
