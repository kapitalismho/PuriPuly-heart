本政策適用於 PuriPuly 應用程式及專案營運的伺服器。外部服務適用其自身政策。

1. 使用統計與您的選擇

- 為估算使用者人數，應用程式會傳送隨機識別碼及 UTC 活動日期。伺服器儲存衍生的識別碼及這些日期，與帳號驗證資訊分開。統計不包含對話、音訊、翻譯或 API 金鑰。
- 新安裝預設開啟統計。在安裝程式的隱私權政策頁面選擇不同意，會在首次啟動前關閉統計，且不影響安裝。之後可在設定中變更；升級會保留您的選擇。
- 關閉統計會停止傳送並刪除本機識別碼。重新開啟會產生新的識別碼。伺服器紀錄會保留至清理時；清理會刪除活動日期距 UTC 今天超過 35 天的紀錄，仍可能保留包括今天在內的 36 個日期的紀錄。

2. 音訊、翻譯與整合

- 本機模型在裝置上處理資料。外部語音辨識會傳送音訊；外部翻譯會傳送文字及必要脈絡。所選服務及自訂伺服器會收到為其設定的驗證資訊，並適用各自的保留及訓練政策。
- 新安裝選擇 Bilibili 在 index-translate.bilibili.com 提供的免金鑰 Index-Translate 35B API。啟動應用程式及選擇該服務時，即使翻譯關閉，也會傳送不含對話內容的合成文字請求以檢查可用性。一般翻譯可能將同一請求傳送兩次。服務無法使用時，儲存的選擇會改為 Gemma 4 Managed；若已確認 Managed 額度耗盡，則改為 Gemma 4 OpenRouter。所選路徑使用其正常的驗證及處理流程。不保證免費可用。
- 代管翻譯會連同使用者參照值傳送至 OpenRouter 及其推論供應商，不經過專案驗證伺服器。選擇本機模型或關閉相應功能可避免外部處理。
- VRChat 脈絡可能包含參與人數，但不含姓名或原始日誌。OSC 向設定的目標傳送字幕及控制資訊，自動連線時會在區域網路中探索及公告服務。預設目標位於本機；可在設定中變更或關閉。

3. 代管帳號與安全

Discord、QQ 及代管服務會處理驗證資料、帳號參照值、安裝/裝置識別碼及硬體雜湊，用於存取控制、使用權限、金鑰交付及防止濫用。伺服器紀錄包括使用權限、金鑰發放、獎勵及以 IP 為基礎的安全資訊。這些資訊與選用統計分開，保留期限也不同。活動及金鑰發放彙總會傳送至營運用的 Discord 頻道。

4. 關閉統計後仍會發生的通訊

應用程式啟動時會向 GitHub 檢查更新，並從 Hugging Face 或 ModelScope 等服務下載模型。驗證及外部功能的通訊獨立於統計。使用本機模型並關閉統計，也不會使應用程式完全離線。

更新/下載請求不含統計識別碼、對話或音訊，但接收方及 Cloudflare 基礎設施會處理 IP 位址及一般請求中繼資料。刪除伺服器紀錄不會立即清除備份或舊版本的紀錄。

5. 本機資訊與刪除

設定、模型及日誌主要儲存在 %LOCALAPPDATA%\puripuly-heart。執行階段日誌包含辨識文字及翻譯，紀錄長度有限。Basic 及 Detailed 日誌都會遮蔽符合已知機密資訊模式的內容，但仍可能留下敏感文字。分享日誌前請檢查並遮蔽敏感內容。

認證資料儲存在 Windows 認證管理員或加密檔案中。刪除存放應用程式資料的資料夾不會清除所有認證資料或外部服務紀錄。

6. Puri 助理與自願支援報告

助理請求

Puri 在您傳送訊息時啟動，無需獨立的同意對話框。訊息、必要的對話/工具結果，以及列入允許清單的應用程式狀態和診斷摘要，會經由專案的 relay 傳送至 OpenAI。不會自動包含語音轉寫、翻譯、音訊、原始日誌、完整設定或金鑰。

請僅在設定的安全輸入欄填寫金鑰，切勿在聊天中輸入。已知模式攔截無法辨識所有機密資訊。Puri 歷史儲存在應用程式記憶體中，與語音轉寫分開。重設後可能保留本次執行的報告封存；重新啟動應用程式會清除它。

Broker 驗證安裝身分並簽發短期權杖。Relay 及 OpenAI 收到的是衍生的安裝識別碼（HMAC），而非原始 ID。必要的用量、費用及錯誤統計，以及隨機提示回合識別碼，均與選用統計分開。每日限額按提交的提示回合計算，而非模型呼叫次數或費用。一般 relay 儲存及日誌不保留對話內容、設定值或原始診斷資料。

OpenAI 的 store:false 不等於 Zero Data Retention。依據其資料控制說明（查閱日期：2026-10-30）：
- 除非主動選擇參與，否則 API 資料不會用於訓練。
- 濫用監控內容可保留最多 30 天；因法律或防止傷害需要，可能保留更久。
- 加密提示快取張量可保留最多 24 小時。
- 特殊保留控制需供應商核准。
https://developers.openai.com/api/docs/guides/your-data

自願支援報告

只有點選說明旁的「傳送」才會上傳報告。僅提出建議不會建立或上傳任何內容。報告包含：
- 本次執行的完整 Puri 對話，包括重設前的內容、工具呼叫/結果及通知；不含推理資料。
- 僅目前的應用程式日誌，含辨識文字及翻譯。
- 中繼資料。

遮蔽無法移除所有敏感文字。報告傳送至僅開發者可存取的 R2 儲存空間，生命週期為 30 天；通常在到期後約 24 小時內刪除。Discord 通知僅含案件編號、應用程式版本、壓縮大小及診斷代碼。

報告壓縮後上限為 25 MB，每個安裝實例每日（UTC）最多 3 份，與模型用量分開計算。傳送失敗須主動重試。
