## Finalment, parleu com amics de veritat.

Heu estat en aquesta situació.
Voleu consolar un amic,
però només aconseguiu: "Estàs bé?"

Ja sabeu que un "traductor" no pot transmetre el que teniu al cor.
Per això n'he creat un que sí que pot.

- **Traducció impulsada per LLM** — argot, expressions col·loquials, discurs formal i informal — tot es transmet de manera natural.
- **Memòria de context** — la conversa flueix de manera natural tenint en compte el context previ.
- **Traducció de veu bidireccional** — també tradueix la veu de l'altra persona, amb suport per a subtítols VR.
- **Inici via Discord** — comenceu immediatament sense una configuració complexa.

## Preguntes freqüents

- **Quina és la qualitat de la traducció?**
→ Amb Gemma 4, el resultat és 6 vegades millor que DeepL.

- **Quant triga de parlar a obtenir la traducció?**
→ Amb Gemma 4 i un servei STT al núvol, la latència és d'aproximadament un segon i mig.

- **Costa diners?**
→ Sí, però no immediatament. Els nous usuaris obtenen un crèdit gratuït. Després, els preus són molt baixos — milers de frases per $1.

- **Necessito una clau API?**
→ Sí, però no immediatament. Simplement instal·leu i autentiqueu-vos via Discord.

- **Com funciona la traducció de la veu de l'altra persona?**
→ Funciona millor en converses individuals en entorns silenciosos. A VRChat feu servir Earmuff.

- **El reconeixement de veu és deficient/lent.**
→ Feu servir STT al núvol. A Intel, utilitzeu només nuclis d'alt rendiment.

- **Com es gestionen les dades?**
→ La veu i el contingut de la conversa s'emmagatzemen localment i no s'envien a servidors.

## Ús

1. Descarregueu l'última versió des de [la pàgina de descàrrega](https://github.com/kapitalismho/PuriPuly-heart/releases/latest).
2. Instal·leu PuriPuly.
3. Premeu **STT**.
4. Premeu **TRANS** i autentiqueu-vos via Discord.
5. Premeu **Subtitles** per a subtítols VR.
6. Premeu **Peer** per a la traducció de la veu de l'altre.
7. Activeu OSC a VRChat: Menú ← Configuració ← OSC ← Activar.

---

---

### Si la captura d'àudio no funciona
Si la captura d'àudio no funciona, obriu **Configuració > General** i seguiu aquests passos.

1. Canvieu **Audio Host API** a **Auto** o **MME**.
2. Seleccioneu el micròfon correcte.
3. Reinicieu l'aplicació.

### Utilitzar les vostres claus API

Seguiu la guia del servei que voleu utilitzar.

Per a la traducció, recomanem el model Gemma 4 mitjançant OpenRouter.

Aprofiteu per configurar també ASR — PuriPuly ofereix la millor experiència amb STT al núvol.
Fins i tot amb el mateix Qwen ASR, la diferència entre reconeixement local i al núvol és notable.

Recomanem començar amb Deepgram.
Només registrar-vos obteniu $200 de crèdit gratuït.

```bash

uv run python -m puripuly_heart.main run-gui
```

```bash
black src tests          # Formatar
ruff check src tests     # Linting
python -m pytest         # Proves (recomanat dins de venv)
```

### Superposició VR

La superposició de subtítols VR es construeix des del projecte Rust a `native/overlay/`.

```powershell
cargo test --manifest-path native/overlay/Cargo.toml -q

cargo build `
  --manifest-path native/overlay/Cargo.toml `
  --locked `
  --release `
  --bin PuriPulyHeartOverlay `
  --target-dir target

New-Item -ItemType Directory -Force -Path build/overlay | Out-Null
Copy-Item target/release/PuriPulyHeartOverlay.exe build/overlay/PuriPulyHeartOverlay.exe -Force
Copy-Item third_party/openvr/win64/openvr_api.dll build/overlay/openvr_api.dll -Force

.\build\overlay\PuriPulyHeartOverlay.exe --check-startup-contract
```

### Servei broker

Consulteu `broker/README.md` per a més detalls.

```bash
pnpm install --frozen-lockfile
pnpm run typecheck

pnpm --filter @puripuly-heart/broker run dev
```
