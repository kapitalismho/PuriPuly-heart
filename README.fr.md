## Enfin, parlez comme de vrais amis.

Vous avez été dans cette situation.
Vouliez réconforter un ami,
mais n'avez réussi que: "Tu vas bien?"

Vous savez déjà qu'un "traducteur" ne peut pas transmettre ce que vous avez dans le cœur.
C'est pourquoi j'en ai créé un qui le peut.

- **Traduction propulsée par LLM** — argot, expressions familières, discours formel et informel — tout est transmis naturellement.
- **Mémoire de contexte** — la conversation coule naturellement avec la conscience du contexte précédent.
- **Traduction vocale bidirectionnelle** — traduit aussi la voix de l'autre personne, avec support de sous-titres VR.
- **Démarrage via Discord** — commencez immédiatement sans configuration complexe.

## Questions fréquentes

- **Quelle est la qualité de la traduction?**
→ Avec Gemma 4, le résultat est 6x meilleur que DeepL.

- **Combien de temps ça prend?**
→ Avec Gemma 4 et STT cloud, la latence est d'environ une seconde et demie.

- **Est-ce que ça coûte?**
→ Oui, mais pas tout de suite. Les nouveaux utilisateurs obtiennent un crédit gratuit. Ensuite, les prix sont très bas — des milliers de phrases pour 1$.

- **Ai-je besoin d'une clé API?**
→ Oui, mais pas tout de suite. Installez et authentifiez-vous via Discord.

- **Comment fonctionne la traduction de la voix de l'autre?**
→ Fonctionne mieux en conversations un-à-un dans un environnement calme. Dans VRChat utilisez Earmuff.

- **La reconnaissance vocale est mauvaise/lente.**
→ Utilisez STT cloud. Sur Intel, utilisez uniquement les cœurs de performance.

- **Comment les données sont-elles gérées?**
→ La voix et le contenu de la conversation sont stockés localement et ne sont pas envoyés à des serveurs.

## Utilisation

1. Téléchargez depuis la [page de téléchargement](https://github.com/kapitalismho/PuriPuly-heart/releases/latest).
2. Installez PuriPuly.
3. Appuyez sur **STT**.
4. Appuyez sur **TRANS** et authentifiez-vous via Discord.
5. Appuyez sur **Subtitles** pour les sous-titres VR.
6. Appuyez sur **Peer** pour la traduction de la voix de l'autre.
7. Activez OSC dans VRChat: Menu ← Réglages ← OSC ← Activer.

---

---

### Si la capture audio ne fonctionne pas
Si la capture audio ne fonctionne pas, ouvrez **Paramètres > Général** et suivez ces étapes.

1. Changez **Audio Host API** en **Auto** ou **MME**.
2. Sélectionnez le bon microphone.
3. Redémarrez l'application.

### Utiliser vos propres clés API

Suivez le guide du service que vous souhaitez utiliser.

Pour la traduction, nous recommandons le modèle Gemma 4 via OpenRouter.

Profitez-en pour configurer ASR — PuriPuly offre la meilleure expérience avec un STT cloud.
Même avec le même Qwen ASR, la différence entre la reconnaissance locale et cloud est notable.

Nous recommandons de commencer avec Deepgram.
La simple inscription vous donne $200 de crédit gratuit.

## Développement

### Résumé de l'environnement

| Domaine | Environnement recommandé |
|---|---|
| Application Python | Windows |
| Superposition VR | Windows |
| Service broker | Linux / WSL |

### Application Python

```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
```

```bash
# pip
pip install -e '.[dev]'

# or uv
uv sync --dev
```

```bash
pre-commit install
```

### Lancer l'interface graphique

```bash
# After activating venv
python -m puripuly_heart.main run-gui

# or run via uv
uv run python -m puripuly_heart.main run-gui
```

```bash
# Affiche l'interface cachée pour inspection
python -m puripuly_heart.main run-gui --debug-ui-preview
```

### Tests et linting

```bash
black src tests          # Formatage
ruff check src tests     # Linting
python -m pytest         # Tests (recommandé dans venv)
```

### Superposition VR

La superposition de sous-titres VR est construite à partir du projet Rust sous `native/overlay/`.

```powershell
cargo test --manifest-path native/overlay/Cargo.toml -q

cargo build `
  --manifest-path native/overlay/Cargo.toml `
  --locked `
  --release `
  --bin PuriPulyHeartOverlay `
  --target-dir target

New-Item -ItemType Directory -Force -Path build/overlay | Out-Null
Copy-Item target/release/PuriPulyHeartOverlay.exe build/overlay/PuriPulyHeartOverlay.exe -Force
Copy-Item third_party/openvr/win64/openvr_api.dll build/overlay/openvr_api.dll -Force

.\build\overlay\PuriPulyHeartOverlay.exe --check-startup-contract
```

### Service broker

Voir `broker/README.md` pour les détails.

```bash
pnpm install --frozen-lockfile
pnpm run typecheck
pnpm exec vitest run
pnpm --filter @puripuly-heart/broker run verify:config
pnpm --filter @puripuly-heart/broker run dev
```
