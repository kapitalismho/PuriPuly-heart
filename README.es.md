## Por fin, habla como amigos de verdad.

Has estado en esa situación.
Querías consolar a un amigo,
pero solo pudiste decir: "¿Estás bien?"

Ya sabes que un "traductor" no puede transmitir lo que tienes en el corazón.
Por eso creé uno que sí puede.

- **Traducción impulsada por LLM** — argot, expresiones coloquiales, habla formal e informal — todo se transmite de forma natural.
- **Memoria de contexto** — la conversación fluye naturalmente teniendo en cuenta el contexto previo.
- **Traducción de voz bidireccional** — también traduce la voz de la otra persona, con soporte de subtítulos VR.
- **Inicio vía Discord** — comienza de inmediato sin configuración compleja.

## Preguntas frecuentes

- **¿Qué tan buena es la calidad de la traducción?**
→ Con Gemma 4, el resultado es 6 veces mejor que DeepL.

- **¿Cuánto tarda?**
→ Con Gemma 4 y STT en la nube, la latencia es de aproximadamente un segundo y medio.

- **¿Cuesta dinero?**
→ Sí, pero no de inmediato. Los nuevos usuarios obtienen crédito gratuito. Después, los precios son muy bajos — miles de frases por $1.

- **¿Necesito una clave API?**
→ Sí, pero no de inmediato. Solo instala y autentícate vía Discord.

- **¿Cómo funciona la traducción de la voz del otro?**
→ Funciona mejor en conversaciones uno a uno en ambientes silenciosos. En VRChat usa Earmuff.

- **El reconocimiento de voz es deficiente/lento.**
→ Usa STT en la nube. En Intel, usa solo núcleos de rendimiento.

- **¿Cómo se manejan los datos?**
→ La voz y el contenido de la conversación se almacenan localmente y no se envían a servidores.

## Uso

1. Descarga la última versión de la [página de descarga](https://github.com/kapitalismho/PuriPuly-heart/releases/latest).
2. Instala PuriPuly.
3. Presiona **STT**.
4. Presiona **TRANS** y autentícate vía Discord.
5. Presiona **Subtitles** para subtítulos VR.
6. Presiona **Peer** para traducción de voz del otro.
7. Activa OSC en VRChat: Menú ← Ajustes ← OSC ← Activar.

---

---

### Si la captura de audio no funciona
Si la captura de audio no funciona, abra **Configuración > General** y siga estos pasos.

1. Cambie **Audio Host API** a **Auto** o **MME**.
2. Seleccione el micrófono correcto.
3. Reinicie la aplicación.

---

### Nota para usuarios en China

Si Soniox/Gemini/Deepgram están bloqueados en su región, use la siguiente combinación:

- STT: **Qwen ASR**
- LLM: **DeepSeek V4 Flash**

   > Puede autenticarse a través de QQ en lugar de Discord.

### Usar sus propias claves API

Siga la guía del servicio que desee usar.

Para traducción, recomendamos el modelo Gemma 4 a través de OpenRouter.

Aproveche para configurar ASR — PuriPuly ofrece la mejor experiencia con STT en la nube.
Incluso con el mismo Qwen ASR, la diferencia entre reconocimiento local y en la nube es notable.

Recomendamos empezar con Deepgram.
Solo registrarse le da $200 de crédito gratis.

## Desarrollo

### Resumen del entorno

| Área | Entorno recomendado |
|---|---|
| Aplicación Python | Windows |
| Superposición VR | Windows |
| Servicio broker | Linux / WSL |

### Aplicación Python

```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
```

```bash
# pip
pip install -e '.[dev]'

# or uv
uv sync --dev
```

```bash
pre-commit install
```

### Ejecutar la interfaz gráfica

```bash
# After activating venv
python -m puripuly_heart.main run-gui

# or run via uv
uv run python -m puripuly_heart.main run-gui
```

```bash
# Muestra la interfaz oculta para inspección
python -m puripuly_heart.main run-gui --debug-ui-preview
```

### Pruebas y linting

```bash
black src tests          # Formateo
ruff check src tests     # Linting
python -m pytest         # Pruebas (recomendado en venv)
```

### Superposición VR

La superposición de subtítulos VR se construye desde el proyecto Rust en `native/overlay/`.

```powershell
cargo test --manifest-path native/overlay/Cargo.toml -q

cargo build `
  --manifest-path native/overlay/Cargo.toml `
  --locked `
  --release `
  --bin PuriPulyHeartOverlay `
  --target-dir target

New-Item -ItemType Directory -Force -Path build/overlay | Out-Null
Copy-Item target/release/PuriPulyHeartOverlay.exe build/overlay/PuriPulyHeartOverlay.exe -Force
Copy-Item third_party/openvr/win64/openvr_api.dll build/overlay/openvr_api.dll -Force

.\build\overlay\PuriPulyHeartOverlay.exe --check-startup-contract
```

### Servicio broker

Consulte `broker/README.md` para más detalles.

```bash
pnpm install --frozen-lockfile
pnpm run typecheck
pnpm exec vitest run
pnpm --filter @puripuly-heart/broker run verify:config
pnpm --filter @puripuly-heart/broker run dev
```
