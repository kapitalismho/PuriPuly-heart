## Sonunda, gerçek arkadaşlar gibi konuşun.

O durumda bulundunuz. Bir arkadaşınızı teselli etmek istediniz ama sadece "İyi misin?" diyebildiniz.

Bir "çevirmenin" kalbinizdekileri iletemeyeceğini zaten biliyorsunuz. Bu yüzden yapabilen bir tane inşa ettim.

- **LLM destekli çeviri** — argo, konuşma dili, resmi ve gayri resmi konuşma — hepsi doğal şekilde aktarılır.
- **Bağlam hafızası** — konuşma önceki bağlamın farkında olarak doğal akar.
- **İki yönlü ses çevirisi** — diğer kişinin sesini de çevirir, VR altyazı desteği ile.
- **Discord ile başlangıç** — karmaşık kurulum olmadan hemen başlayın.

## Sıkça sorulan sorular

- **Çeviri kalitesi nasıl?**
→ Gemma 4 ile sonuç DeepL'den 6 kat daha iyi.

- **Ne kadar sürüyor?**
→ Gemma 4 ve bulut STT ile gecikme yaklaşık bir buçuk saniye.

- **Paraya mal oluyor mu?**
→ Evet, ama hemen değil. Yeni kullanıcılar ücretsiz kredi alır. Sonrasında fiyatlar çok düşük — binlerce cümle 1$'a.

- **API anahtarı gerekiyor mu?**
→ Evet, ama hemen değil. Sadece yükleyin ve Discord ile kimlik doğrulayın.

- **Diğerinin sesini çevirmek nasıl çalışır?**
→ Sessiz ortamlarda birebir görüşmelerde en iyi çalışır. VRChat'te Earmuff kullanın.

- **Ses tanıma kötü/yavaş.**
→ Bulut STT kullanın. Intel'de sadece performans çekirdeklerini kullanın.

- **Veriler nasıl işleniyor?**
→ Ses ve konuşma içeriği yerel olarak saklanır ve sunuculara gönderilmez.

## Kullanım

1. [İndirme sayfasından](https://github.com/kapitalismho/PuriPuly-heart/releases/latest) son sürümü indirin.
2. PuriPuly'yi yükleyin.
3. **STT**'ye basın.
4. **TRANS**'a basın ve Discord ile kimlik doğrulayın.
5. **Subtitles**'a basın VR altyazıları için.
6. **Peer**'a basın diğerinin sesini çevirmek için.
7. VRChat'te OSC'yi etkinleştirin: Menü ← Ayarlar ← OSC ← Etkinleştir.

---

---

### Ses yakalama çalışmazsa
Ses yakalama çalışmazsa, **Ayarlar > Genel**'i açın ve şu adımları izleyin.

1. **Audio Host API**'yı **Auto** veya **MME** olarak değiştirin.
2. Doğru mikrofonu seçin.
3. Uygulamayı yeniden başlatın.

---

### Çin'deki kullanıcılar için not

Bölgenizde Soniox/Gemini/Deepgram engellenmişse, şu kombinasyonu kullanın:

- STT: **Qwen ASR**
- LLM: **DeepSeek V4 Flash**

   > Discord yerine QQ üzerinden kimlik doğrulaması yapabilirsiniz.

### Kendi API anahtarlarınızı kullanma

Kullanmak istediğiniz hizmetin kılavuzunu izleyin.

Çeviri için OpenRouter üzerinden Gemma 4 modelini öneriyoruz.

ASR'yi de yapılandırın — PuriPuly bulut STT ile en iyi deneyimi sunar.
Aynı Qwen ASR ile bile yerel ve bulut tanıma arasındaki fark belirgindir.

Deepgram ile başlamanızı öneriyoruz.
Sadece kayıt olmak $200 ücretsiz kredi verir.

## Geliştirme

### Ortam özeti

| Alan | Önerilen ortam |
|---|---|
| Python uygulaması | Windows |
| VR katmanı | Windows |
| Broker hizmeti | Linux / WSL |

### Python uygulaması

```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
```

```bash
# pip
pip install -e '.[dev]'

# or uv
uv sync --dev
```

```bash
pre-commit install
```

### GUI'yi çalıştırma

```bash
# After activating venv
python -m puripuly_heart.main run-gui

# or run via uv
uv run python -m puripuly_heart.main run-gui
```

```bash
# Denetim için gizli arayüzü gösterir
python -m puripuly_heart.main run-gui --debug-ui-preview
```

### Test ve linting

```bash
black src tests          # Biçimlendirme
ruff check src tests     # Linting
python -m pytest         # Testler (venv'de önerilir)
```

### VR katmanı

VR altyazı katmanı `native/overlay/` altındaki Rust projesinden oluşturulur.

```powershell
cargo test --manifest-path native/overlay/Cargo.toml -q

cargo build `
  --manifest-path native/overlay/Cargo.toml `
  --locked `
  --release `
  --bin PuriPulyHeartOverlay `
  --target-dir target

New-Item -ItemType Directory -Force -Path build/overlay | Out-Null
Copy-Item target/release/PuriPulyHeartOverlay.exe build/overlay/PuriPulyHeartOverlay.exe -Force
Copy-Item third_party/openvr/win64/openvr_api.dll build/overlay/openvr_api.dll -Force

.\build\overlay\PuriPulyHeartOverlay.exe --check-startup-contract
```

### Broker hizmeti

Ayrıntılar için `broker/README.md`'ye bakın.

```bash
pnpm install --frozen-lockfile
pnpm run typecheck
pnpm exec vitest run
pnpm --filter @puripuly-heart/broker run verify:config
pnpm --filter @puripuly-heart/broker run dev
```
