# VR photo translation

- **Use:** With PuriPuly and SteamVR running, VRChat camera photos can be translated in VR, even with CAPTIONS off. Within 10 seconds of a shot, the user looks at their right wrist, grabs the icon there with the left grip and pulls it away; the translated photo appears in the left hand. Only the latest photo can be reopened, for 10 minutes, without a new request. Text is translated into the Self input language; there is no separate photo language, and changing Self input also changes speech recognition. Only the VRChat folder inside the Windows Pictures folder is watched, not a custom VRChat picture folder.
- **Settings:** Image translation settings hold the on/off switch, the Model (GPT-6 Luna by default, or Gemini 3.5 Flash-Lite) and the Connection the user chose (for Luna: Managed by default, ChatGPT sign-in or OpenAI API key; for Gemini: Gemini API key). There is no automatic fallback, and a chosen connection without its sign-in or key shows no wrist icon. The settings also show today's remaining Managed count and Delete Translated Photos, which moves successfully translated originals to the Recycle Bin when their 10-minute retention ends. Only Managed uses the hosted service, which allows {{photo_daily_allowance}} photos per installation per UTC day.
- **Troubleshooting:** first check observed `photo.enabled` and `photo.route`: off, or a chosen route whose sign-in/key is missing, shows no wrist icon. Then check that PuriPuly and SteamVR were running, the shot was saved to the watched folder and the pull came within 10 seconds. With Managed, heavy use can exhaust the daily allowance; Image translation settings show the remaining count, which chat cannot observe. Chat has no photo remedy, so offer the report card when a photo fault persists.
