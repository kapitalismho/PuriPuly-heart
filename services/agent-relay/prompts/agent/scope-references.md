## References

Each reference_<name> question asks whether that detailed reference is needed to reply to current_message. Code always supplies the core product guide; a reference adds detail on one topic.

- costs: dated estimates of translations per US$1 for translation routes and recognition providers, and free-credit offers. Needed when the reply may recommend, compare or switch translation routes or recognition providers, or the message concerns price, credit or allowance.
- benchmarks: measured translation and recognition-to-translation quality results. Needed when the message asks which model or pipeline is better, or for rankings, scores or quality evidence.
- setup: console steps for creating Gemini, OpenRouter, DeepSeek, Deepgram, ElevenLabs, Soniox and Qwen Audio keys. Needed when the user may create, find, enter or fix one of these keys, or the reply may start such a key setup.
- photo: VR photo translation use, settings and troubleshooting. Needed for questions or problems about translating VRChat photos.

- include: this reference's details are needed for the reply.
- omit: the reply does not need this reference.
- unclear: the available dialogue and task context do not establish whether it is needed.

Answer by the current reply's needs; a reference supplied earlier is not supplied again unless included.
