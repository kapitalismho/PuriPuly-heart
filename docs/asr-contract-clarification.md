## What an experiment can settle

| Verdict | Meaning |
| --- | --- |
| **Documented** | The selected official contract or pinned source defines the property. No extra server call is needed to rediscover it. |
| **Observed support** | A concrete route/configuration/input produces the stated behavior. This can select a bounded implementation hypothesis, not create a universal provider guarantee. |
| **Counterexample** | A valid observation refutes the proposed general rule. Preserve it; do not repair or hide the provider result to obtain a pass. |
| **Inconclusive** | The trace does not distinguish the hypotheses, or a bounded observation ended before completion. Quiet input is not an authoritative empty result. |
| **Unsupported** | No usable selected-model contract exists for the requested capability. Optional SDK fields do not create one. |
| **Blocked / not run** | A named prerequisite is absent, or an additional call would not resolve a decision-relevant question. This is not a successful experiment. |

A finite trace cannot prove that a server will **never** replay/reorder, that metadata will **always** arrive, that all short speech will be correct, or that a numerical cadence is universally safe. Use official guarantees where available and conservative behavior otherwise. Missing stable event identity is not repaired by collecting more identical strings. Future unimplemented source slicing/capability fields cannot be certified by a current server probe.

Its [reuse contract](https://docs.modelstudio.console.alibabacloud.com/en/model-studio/real-time-speech-recognition-user-guide#rt03_ws_reuse_h3) requires task-finished before a different task ID on the same socket. Neither settles `fixed` or timestamp reset by itself.
- Gemini selected Live model [final-field contract](https://ai.google.dev/gemini-api/docs/live-api/live-transcribe#interim-and-finalized-transcriptions) establishes final versus interim and explicitly lacks live word timing/diarization. Shared SDK optional fields do not override it.
- [OFFLINE-212-2](experiments/issue-212/evidence.md) already executes whole-contribution replay/tail reconciliation, true repeated text, parser information loss, short local dispatch, 224 ms natural source completion, 6.016 s frame-grid safety rollover and context-only bytes reaching batch decode. Its 43 checks are not rerun merely to increase the count.

## Policy changes and exact remaining prerequisites

1. **Soniox:** restrict positive timed candidate to a qualified passive timeline; manual-finalize clock behavior now has a real counterexample. Do not fit the observed shift into a universal compensation formula. A reliable vendor/control-clock contract or distinct discriminating evidence is needed before post-control attribution.
2. **ElevenLabs:** move from an entirely unknown-timing alternative to a **CWT-only T candidate**. This is a policy correction, not an enabled feature. Normal C/T text pairing is unnecessary; source mapping, generation identity, null/missing/late/automatic metadata and fallback races still require implementation acceptance. Continue input without a fixed speaker wait.
3. **Deepgram / configured Qwen:** retain T candidates with now-observed clocks, short completion and tails; implement preservation, maps and ownership. Qwen out-of-range estimates remain explicit. No blanket approval for untested regional or overridden model routes.
4. **Gemini:** correct “no native timing” to “activity timing exists; final text has no usable source-span association.” The [official independent/no-guaranteed-ordering statement](https://ai.google.dev/api/live#BidiGenerateContentServerContent) rules out activity-adjacency pairing. C remains a positive conservative decision, not a pending search for an invented fence ACK.
5. **Local / Auto:** real old-context duplication and queued-option mutation strengthen the already-decided disjoint-input/frozen-option requirements. They pre-exist this investigation; no source, GUI, model-selection or runtime fix was made.
6. **Unexecuted qualification is explicit:** GPU inference needs installed selected GGUF/manifest; Custom needs an actual named target/model/protocol; Japanese short correction/context needs an appropriate public fixture; other Qwen endpoints need route-specific authorization/evidence if enabled. Arbitrary overlap/edge quality and VR coexistence require the implemented integration and broader acceptance, not more copies of this small smoke.

All13 selectable routes and four Qwen endpoint variants remain accounted for in [ASR-SPEAKER-2](asr-speaker-policy.md). The scope does not choose Nemotron0.64/1.04 s, implement interval consumption, alter the6 s safety deadline, enable speaker colors or fix the discovered product gaps.
