## Endelig, tal som rigtige venner.

Du har været i den situation.
Ville trøste en ven,
men kunne kun sige: "Er du okay?"

Du ved allerede, at en "oversætter" ikke kan bære det, der er i dit hjerte.
Derfor byggede en, der kan.

- **LLM-drevet lokalisering** — slang, talemåde, formel og uformel tale — alt gengives naturligt.
- **Konteksthukommelse** — samtalen flyder naturligt med bevidsthed om tidligere kontekst.
- **Tovejs stemmeoversættelse** — oversætter også den anden persons stemme, med VR undertekst support.
- **Start via Discord** — kom i gang med det samme uden kompleks opsætning.

## Ofte stillede spørgsmål

- **Hvor god er oversættelseskvaliteten?**
→ Med Gemma 4 er resultatet 6x bedre end DeepL.

- **Hvor lang tid tager det?**
→ Med Gemma 4 og cloud STT er ventetiden omkring halvandet sekund.

- **Koster det penge?**
→ Ja, men ikke med det samme. Nye brugere får gratis kredit. Derefter er priserne meget lave — tusindvis af sætninger for $1.

- **Har jeg brug for en API nøgle?**
→ Ja, men ikke med det samme. Bare installer og autentificer via Discord.

- **Hvordan fungerer oversættelse af den andens stemme?**
→ Fungerer bedst i en-til-en samtaler i stille miljøer. I VRChat brug Earmuff.

- **Stemmegenkendelse er dårlig/langsom.**
→ Brug cloud STT. På Intel, brug kun ydelseskerner.

- **Hvordan håndteres data?**
→ Stemme og samtaleindhold gemmes lokalt og sendes ikke til servere.

## Brug

1. Download den nyeste version fra [downloadsiden](https://github.com/kapitalismho/PuriPuly-heart/releases/latest).
2. Installer PuriPuly.
3. Tryk **STT**.
4. Tryk **TRANS** og autentificer via Discord.
5. Tryk **Subtitles** for VR undertekster.
6. Tryk **Peer** for oversættelse af den andens stemme.
7. Aktiver OSC i VRChat: Menu ← Indstillinger ← OSC ← Aktiver.

### Hvis lydoptagelse ikke virker
Hvis lydoptagelse ikke virker, åbn **Indstillinger > Generelt** og følg disse trin.

1. Skift **Audio Host API** til **Auto** eller **MME**.
2. Vælg den korrekte mikrofon.
3. Genstart appen.

### Brug af dine egne API-nøgler

Følg guiden for den tjeneste du vil bruge.

Til oversættelse anbefaler vi Gemma 4-modellen via OpenRouter.

Indstil også ASR — PuriPuly leverer den bedste oplevelse med cloud STT.
Selv med den samme Qwen ASR er forskellen mellem lokal og cloud genkendelse mærkbar.

Vi anbefaler at starte med Deepgram.
Bare tilmelding giver $200 i gratis kredit.

## Udvikling

### Miljøoversigt

| Område | Anbefalet miljø |
|---|---|
| Python-app | Windows |
| VR-overlejring | Windows |
| Broker-tjeneste | Linux / WSL |

### Python-app

```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
```

```bash
# pip
pip install -e '.[dev]'

# or uv
uv sync --dev
```

```bash
pre-commit install
```

### Kør GUI

```bash
# After activating venv
python -m puripuly_heart.main run-gui

# or run via uv
uv run python -m puripuly_heart.main run-gui
```

```bash
# Viser skjult UI til inspektion
python -m puripuly_heart.main run-gui --debug-ui-preview
```

### Test og linting

```bash
black src tests          # Formatering
ruff check src tests     # Linting
python -m pytest         # Test (anbefalet i venv)
```

### VR-overlejring

VR-undertekstoverlejringen er bygget fra Rust-projektet under `native/overlay/`.

```powershell
cargo test --manifest-path native/overlay/Cargo.toml -q

cargo build `
  --manifest-path native/overlay/Cargo.toml `
  --locked `
  --release `
  --bin PuriPulyHeartOverlay `
  --target-dir target

New-Item -ItemType Directory -Force -Path build/overlay | Out-Null
Copy-Item target/release/PuriPulyHeartOverlay.exe build/overlay/PuriPulyHeartOverlay.exe -Force
Copy-Item third_party/openvr/win64/openvr_api.dll build/overlay/openvr_api.dll -Force

.\build\overlay\PuriPulyHeartOverlay.exe --check-startup-contract
```

Se `broker/README.md` for detaljer.

```bash
pnpm install --frozen-lockfile

pnpm --filter @puripuly-heart/broker run dev
```
